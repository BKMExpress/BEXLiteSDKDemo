# BEX Lite SDK Demo

Bu repo, BEX Lite SDK’nın Android demo uygulamasını içerir. XML ve Jetpack Compose örnek entegrasyonları inceleyebilirsiniz.

Detaylı entegrasyon rehberi için:

https://entegrasyon.bkmexpress.com.tr/develop/guide/android-sdk/lite-sdk

## Gereksinimler

|                      |                          |
|----------------------|--------------------------|
| Min SDK              | 24                       |
| Target / Compile SDK | 36                       |
| Kotlin               | 2.0+                     |
| JDK                  | 11                       |
| Lite SDK             | `com.bkm.mobil:lite-sdk` |
